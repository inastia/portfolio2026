AI Website Design System Resources

Two free templates for auditing an AI-built website, turning inconsistent design decisions into a system, and giving that system back to AI in a form it can follow.

I created these while consulting on a website built almost entirely through AI. You can read about the full process in my Medium article.

Design System Template

A compact source-of-truth file for documenting your site's section names, typography, colors, spacing, and responsive navigation.

Download template

Design System Process

A step-by-step workflow for auditing the existing site, making design decisions, completing the Design System Template, and preparing the system for handoff.

Download process

How to use these files

Start with the Process file to audit your site and work through the design decisions. Then complete the Design System Template with the final values. Attach the completed template at the beginning of future AI conversations about your website so the existing system is available before new design decisions are made.
